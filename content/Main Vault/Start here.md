# Start here

## One-time setup (5 minutes)
1. Unzip this kit into the top level of your vault.
2. Settings → Core plugins: turn on **Templates** and **Bases**.
3. Settings → Templates → Template folder location: `templates`
4. Settings → Files and links → Default location for new notes: `00 Inbox`
5. Settings → Hotkeys → search "Insert template" → set it to `Alt+T`

## Daily use
- New thought? Press `Ctrl+N`, type a title, press `Alt+T`, pick **Fleeting**, and write. Don't organise.
- New book or reading? Make the note in `10 Sources` with the **Source** template.

## Processing (every day or two)
Open **Bases/Inbox**. For each fleeting note, choose one:
- **It's an idea worth keeping:** make a **Permanent** note in `20 Notes`. Rewrite it in your own words, fill in `areas`, and link at least one other note.
- **It's about a book or reading:** add it to the right Source note.
- **Not now:** move it to `40 Compost`.

Then delete the fleeting note, or move it to Compost.

## Weekly (15 minutes)
- Look at **Bases/Bridges**: notes linking two or more areas. These are often your most original ideas.
- Add new permanent notes to the relevant Map in `30 Maps`.

## The six areas (always spell them the same way)
`engineering` · `psychotherapy` · `education` · `spirituality` · `expressive-arts` · `gurdjieff`

## Publishing
Only notes with `publish: true` appear on rosswell.net (with explicit-publish turned on).
